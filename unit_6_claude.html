§ 6.2

Point Estimation

การประมาณค่าพารามิเตอร์ด้วยตัวเลข ตัวเดียว และเกณฑ์ที่ใช้เปรียบเทียบว่าตัวประมาณตัวไหน ดีกว่ากัน

Definition 6.1 — Point Estimate

Point estimate ของพารามิเตอร์ θ คือค่าตัวเลข θ^ ที่คำนวณจากสถิติ Θ^

Example 6.1 — ประมาณ μ และ σ²

ข้อมูล: x₁=25, x₂=30, x₃=29, x₄=31

Point Estimate ของ μ
x̄ = (25+30+29+31)/4 = 115/4 = 28.75
Point Estimate ของ σ²
s² = Σ(xᵢ−x̄)²/(n−1) = 20.75/3 = 6.9

คุณสมบัติของตัวประมาณ

Definition 6.2 — Unbiased Estimator

ตัวประมาณที่ไม่เอนเอียง (Unbiased)

Θ^ เป็น Unbiased Estimator ของ θ ถ้า E(Θ^) = θ ตัวอย่าง: E(X̄) = μ → X̄ เป็น unbiased estimator ของ μ E(S²) = σ² → S² เป็น unbiased estimator ของ σ²
ทำไม S² = Σ(Xᵢ−X̄)²/(n−1)? หารด้วย n−1 (ไม่ใช่ n) เพื่อให้ E(S²) = σ² — พิสูจน์โดย Bessel's correction
Definition 6.3 — Most Efficient Estimator

ตัวประมาณที่มีประสิทธิภาพสูงสุด

ถ้า Θ^₁ และ Θ^₂ เป็น unbiased estimators ของ θ ทั้งคู่

ถ้า σ²(Θ^₁) < σ²(Θ^₂) → Θ^₁ มีประสิทธิภาพมากกว่า Θ^₂ Most Efficient Estimator = unbiased estimator ที่มี variance น้อยที่สุด
Example 6.3 — n=7, E(Xᵢ)=μ, Var(Xᵢ)=σ²
Θ^₁ = (X₁+...+X₇)/7
Θ^₂ = (2X₁−X₆+X₄)/2

Var(Θ^₁) = σ²/7
Var(Θ^₂) = 3σ²/2
สรุปผล
σ²/7 ≈ 0.143σ² ✓ น้อยกว่า
3σ²/2 = 1.5σ² ✗ มากกว่า

∴ Θ^₁ ดีกว่า Θ^₂
Theorem 6.1 — Cramer-Rao Inequality

ขอบเขตล่างของ Variance

Var(Θ^) ≥ 1 / { n · E[(d/dθ ln f(x;θ))²] } ถ้า Var(Θ^) = Cramer-Rao lower bound → Θ^ เป็น Minimum Variance Unbiased Estimator (MVUE) → เรียกว่า "Efficient Estimator"
Ex 6.4: X̄ จากประชากร Normal มี Var(X̄) = σ²/n ซึ่งเท่ากับ Cramer-Rao bound → X̄ เป็น MVUE ของ μ
Definition 6.4 + Theorem 6.2 — Consistent Estimator

Θ^n เป็น Consistent Estimator ของ θ ถ้า lim(n→∞) P(|Θ^n − θ| < ε) = 1 หรือ lim Θ^n = θ


Theorem 6.2: Θ^n เป็น consistent ถ้า (1) เป็น unbiased และ (2) Var(Θ^n) → 0 เมื่อ n → ∞


Ex 6.5: X̄ เป็น consistent ของ μ เพราะ lim Var(X̄) = lim σ²/n = 0 ✓

สรุปคุณสมบัติของตัวประมาณ

คุณสมบัติ เงื่อนไข ความหมาย
Unbiased E(Θ^) = θ ค่าคาดหวังตรงกับพารามิเตอร์จริง
Efficient Var(Θ^) น้อยที่สุดในบรรดา unbiased estimators ความแปรปรวนน้อยที่สุด → แม่นยำที่สุด
Consistent Θ^n → θ เมื่อ n → ∞ ยิ่ง n มาก ยิ่งใกล้ค่าจริง
MVUE Var = Cramer-Rao bound Minimum Variance Unbiased Estimator
§ 6.3

Interval Estimation

แทนที่จะประมาณเป็นจุดเดียว เราสร้าง ช่วงความเชื่อมั่น ที่มีความน่าจะเป็น (1−α)×100% ที่จะครอบคลุมค่าพารามิเตอร์จริง

Confidence Interval

ช่วง θ^L < θ < θ^U โดยที่ P(θ^L < θ < θ^U) = 1 − α


(1−α)×100% เรียกว่า Confidence Coefficient หรือ Degree of Confidence

α = 0.05 → 95% CI
x̄ − z₀.₀₂₅(σ/√n) < μ < x̄ + z₀.₀₂₅(σ/√n) z₀.₀₂₅ = 1.96
x̄−1.96σ/√nμx̄+1.96σ/√n
α = 0.01 → 99% CI
x̄ − z₀.₀₀₅(σ/√n) < μ < x̄ + z₀.₀₀₅(σ/√n) z₀.₀₀₅ = 2.575
x̄−2.575σ/√nμx̄+2.575σ/√n
ความกว้าง CI: ยิ่ง Confidence Level สูง (α ต่ำ) → CI ยิ่งกว้าง | ยิ่ง n มาก → CI ยิ่งแคบ (แม่นยำขึ้น) ต้องแลกระหว่าง ความแม่นยำ กับ ความเชื่อมั่น

Single Sample: Estimating the Mean

Z-distt-dist

เลือกสูตรตาม ทราบ/ไม่ทราบ σ และ ขนาดตัวอย่าง n

Definition 6.4 — σ ทราบค่า (ทุก n)

Case 1: σ Known

x̄ − z_{α/2}·(σ/√n) < μ < x̄ + z_{α/2}·(σ/√n) ใช้ได้: ประชากรปกติ (ทุก n) หรือ n ≥ 30 (CLT)
Definition 6.5 — σ ไม่ทราบ, n ≥ 30

Case 2: σ Unknown, n ≥ 30

x̄ − z_{α/2}·(s/√n) < μ < x̄ + z_{α/2}·(s/√n) แทน σ ด้วย s เพราะ n มากพอ → distribution ยังปกติ
Definition 6.6 — σ ไม่ทราบ, n < 30

Case 3: σ Unknown, n < 30 → ใช้ t-distribution

x̄ − t_{α/2}·(s/√n) < μ < x̄ + t_{α/2}·(s/√n) t_{α/2} มี ν = n−1 degrees of freedom T = (X̄ − μ) / (S/√n) ~ t(n−1)

เลือกสูตรอย่างไร?

เงื่อนไขสูตรCritical Value
รู้ σ (ทุก n) / ไม่รู้ σ แต่ n ≥ 30 x̄ ± z_{α/2}·(σ หรือ s)/√n z (Normal table)
ไม่รู้ σ, n < 30, ประชากรปกติ x̄ ± t_{α/2}·s/√n t(ν=n−1)
Example 6.6 — สังกะสีในแม่น้ำ

x̄=2.6, σ=0.3, n=36 → หา 95% และ 99% CI

1
95% CI: z₀.₀₂₅ = 1.96
2.6±1.96×(0.3/√36) = 2.6±0.098
2.50 < μ < 2.70
2
99% CI: z₀.₀₀₅ = 2.575
2.6±2.575×(0.3/√36)
2.47 < μ < 2.73
Example 6.9 — กรดซัลฟิวริก (n=7)

ข้อมูล: 9.8, 10.2, 10.4, 9.8, 10.0, 10.2, 9.6
→ หา 95% CI (ไม่รู้ σ, n<30)

1
x̄ = 70/7 = 10.0, s ≈ 0.283
2
t₀.₀₂₅(6) = 2.447
10.0 ± 2.447×(0.283/√7)
3
9.74 < μ < 10.26
Theorem 6.3 & 6.4 — Error & Sample Size

ขนาดตัวอย่างที่ต้องการ

Error ≤ e เมื่อ e = z_{α/2}·σ/√n → Sample size ที่ต้องการ: n = (z_{α/2}·σ / e)² ปัดขึ้นเสมอ! เช่น 138.3 → 139
Example 6.8 — จาก Ex 6.6 ต้องการ error < 0.05 ด้วย 95% confidence
n = [(1.96)(0.3)/0.05]² = [11.76]² = 138.3 ≈ 139
§ 6.5

Two Samples: Estimating μ₁ − μ₂

เปรียบเทียบ ค่าเฉลี่ยสองกลุ่ม ที่เป็นอิสระต่อกัน โดยสร้าง CI สำหรับ μ₁ − μ₂ หรือ μ_D (Paired)

Definition 6.7 — σ₁², σ₂² ทราบ / n₁,n₂ ≥ 30
(x̄₁−x̄₂) ± z_{α/2}·√(σ₁²/n₁ + σ₂²/n₂)
Ex 6.10: Engine A: x̄=36, σ=6, n=75 | Engine B: x̄=42, σ=8, n=50
96% CI → z₀.₀₂ = 2.05
3.43 < μ_B−μ_A < 8.57
Definition 6.8 — σ₁², σ₂² ไม่ทราบ, n₁,n₂ ≥ 30
(x̄₁−x̄₂) ± z_{α/2}·√(s₁²/n₁ + s₂²/n₂)
Definition 6.9 — σ₁²=σ₂², n₁,n₂ < 30

ใช้ Pooled Variance

s²_p = [(n₁−1)s₁²+(n₂−1)s₂²]/(n₁+n₂−2) (x̄₁−x̄₂) ± t_{α/2}·s_p·√(1/n₁+1/n₂) ν = n₁+n₂−2
Ex 6.12: s²_p = 19.52, t₀.₀₂₅(23) = 2.069
−0.72 < μ₁−μ₂ < 6.72
Definition 6.10 — σ₁²≠σ₂², n₁,n₂ < 30

ใช้ Welch's approximation

(x̄₁−x̄₂) ± t_{α/2}·√(s₁²/n₁+s₂²/n₂) ν = (s₁²/n₁+s₂²/n₂)² / [(s₁²/n₁)²/(n₁−1) + (s₂²/n₂)²/(n₂−1)]
Ex 6.13: Tires A vs B, ν=21
−2936 < μ₂−μ₁ < 6536
Definition 6.11 — Paired Observations

ข้อมูลจับคู่ (Dependent Samples)

เมื่อสองกลุ่มไม่เป็นอิสระกัน (เช่น วัดก่อน-หลัง) ให้คำนวณ dᵢ = x₁ᵢ − x₂ᵢ

d̄ = Σdᵢ/n , s_d = √[Σdᵢ²−nd̄²]/(n−1) d̄ − t_{α/2}·(s_d/√n) < μ_D < d̄ + t_{α/2}·(s_d/√n) ν = n−1
Ex 6.14: โปรแกรมเมอร์ 12 คน, ภาษา 1 vs ภาษา 2
d̄ = 0.67, s_d = 2.96, t₀.₀₂₅(11) = 2.201
−1.21 < μ_D < 2.55

เลือกสูตรอย่างไร?

เงื่อนไขสูตรν (df)
รู้ σ₁,σ₂ หรือ n₁,n₂≥30Z, ใช้ σ หรือ s—
ไม่รู้ σ, n<30, σ₁²=σ₂²t, Pooled s_pn₁+n₂−2
ไม่รู้ σ, n<30, σ₁²≠σ₂²t, WelchWelch's formula
ข้อมูลจับคู่t บน dᵢn−1
§ 6.6

Single Sample: Estimating a Proportion

Z-distribution

ประมาณ สัดส่วน p ของประชากร เช่น สัดส่วนของเสีย, สัดส่วนผู้สนับสนุน

Point Estimator

p^ = X/n (X คือจำนวน success ใน n trials)


E(p^) = p → p^ เป็น unbiased estimator ของ p

Var(p^) = pq/n , q = 1−p

Definition 6.12 — CI สำหรับ p
p^ − z_{α/2}·√(p^q^/n) < p < p^ + z_{α/2}·√(p^q^/n) Z = (p^ − p) / √(pq/n) ~ N(0,1) เมื่อ n ใหญ่พอ
Example 6.15 — ครัวเรือนที่ subscribe HBO (n=500, x=340)
1
p^ = 340/500 = 0.68, q^ = 0.32
2
95% CI: z₀.₀₂₅ = 1.96
0.68 ± 1.96·√(0.68×0.32/500)
3
0.64 < p < 0.72
Theorem 6.5 — Sample Size (ทราบ p^)
n = z²_{α/2}·p^q^ / e² Ex 6.16: p^=0.68, e=0.02, 95% n = (1.96)²(0.68)(0.32)/(0.02)² = 2090
Theorem 6.6 — Sample Size (ไม่ทราบ p^)
n = z²_{α/2} / (4e²) ใช้เมื่อไม่มีข้อมูลเดิม Conservative → p^q^ = 0.25 (max) Ex 6.17: e=0.02, 95% n = (1.96)²/(4×0.02²) = 2401

Two Samples: Estimating p₁ − p₂

เปรียบเทียบ สัดส่วนสองกลุ่ม ที่เป็นอิสระต่อกัน

Definition 6.13 — CI สำหรับ p₁ − p₂

Point estimate: p^₁ − p^₂ = x₁/n₁ − x₂/n₂

(p^₁−p^₂) ± z_{α/2}·√(p^₁q^₁/n₁ + p^₂q^₂/n₂) Z = [(p^₁−p^₂)−(p₁−p₂)] / √(p₁q₁/n₁+p₂q₂/n₂) ~ N(0,1)
Example 6.18 — กระบวนการผลิต (เก่า vs ใหม่)

กระบวนการเก่า: x=75 ของเสียจาก 1500 | กระบวนการใหม่: x=80 ของเสียจาก 2000

1
p^₁ = 75/1500 = 0.05, p^₂ = 80/2000 = 0.04
Point estimate: 0.05−0.04 = 0.01
2
90% CI: z₀.₀₅ = 1.645
SE = √(0.05×0.95/1500 + 0.04×0.96/2000) ≈ 0.0113
3
−0.0017 < p₁−p₂ < 0.0217
ช่วงครอบ 0 → ไม่มีหลักฐานว่าต่างกัน
§ 6.8

Single Sample: Estimating the Variance

χ² Distribution

ใช้ Chi-squared distribution สำหรับสร้าง CI ของ σ²

Definition 6.14 — CI สำหรับ σ²
χ² = (n−1)S²/σ² ~ χ²(n−1) CI สำหรับ σ²: (n−1)s² / χ²_{α/2} < σ² < (n−1)s² / χ²_{1−α/2} χ²_{α/2} = ค่า Chi-squared ที่มีพื้นที่ α/2 ทางขวา χ²_{1−α/2} = ค่า Chi-squared ที่มีพื้นที่ α/2 ทางซ้าย
Example 6.19 — น้ำหนักเมล็ดพันธุ์หญ้า (n=10)

ข้อมูล: 46.4, 46.1, 45.8, 47.0, 46.1, 45.9, 45.8, 46.9, 45.2, 46.0 (decagram)

1
s² = 0.286 (point estimate ของ σ²)
2
χ²₀.₀₂₅(9) = 19.023 | χ²₀.₉₇₅(9) = 2.7
3
(9)(0.286)/19.023 < σ² < (9)(0.286)/2.7
0.135 < σ² < 0.953
สังเกต: Chi-squared distribution ไม่สมมาตร ดังนั้น CI สำหรับ σ² ก็ไม่สมมาตรรอบ s² ต้องใช้สองค่าคริติคัลแยกกัน (ซ้าย/ขวา)
§ 6.9

Two Samples: Estimating σ₁²/σ₂²

F-Distribution

ใช้ F-distribution เปรียบเทียบความแปรปรวนสองกลุ่ม

Definition 6.15 — CI สำหรับ σ₁²/σ₂²
F = σ₂²S₁² / (σ₁²S₂²) ~ F(ν₁=n₁−1, ν₂=n₂−1) (s₁²/s₂²)·[1/f_{α/2}(ν₁,ν₂)] < σ₁²/σ₂² < (s₁²/s₂²)·f_{α/2}(ν₂,ν₁) f_{α/2}(ν₁,ν₂) = F critical value ที่มีพื้นที่ α/2 ทางขวา คุณสมบัติ: f_{1−α/2}(ν₁,ν₂) = 1/f_{α/2}(ν₂,ν₁)
Example 6.20 — บริษัทภาพยนตร์ 2 บริษัท

บ.I: 103, 94, 110, 87, 98 (n₁=5) | บ.II: 97, 82, 123, 92, 175, 88, 118 (n₂=7)

1
s₁² = 76.3, s₂² = 1039.6 | s₁²/s₂² ≈ 0.073
2
ν₁=4, ν₂=6 | f₀.₀₅(6,4) = 6.16, f₀.₀₅(4,6) = 4.53
3
90% CI: 0.073/4.53 < σ₁²/σ₂² < 0.073×6.16
0.0162 < σ₁²/σ₂² < 0.4521
ไม่ครอบ 1 → σ₁² ≠ σ₂²
